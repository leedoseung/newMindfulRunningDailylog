# Plan — Lunge S2 (30-Day) 모집 & 운영 (2026-10-23)

## 요약
런지 챌린지 2기 모집을 위해 (1) 코드의 **"100일/하루100개" 하드코딩을 챌린지-aware** 로 바꾸고, (2) `season_number` 식별자를 도입하며, (3) **S1→ended / S2 insert SQL 템플릿**을 준비한다. 운영 시점의 날짜·제목·이미지는 플레이스홀더로 둔다.

## 결정 사항 (user confirmed)
- **duration = 30일**, **goal_per_day = 100개** (하루 수량은 유지)
- 시작일/모집 마감일 **코드 선작업**, 실제 날짜는 운영 시 치환
- 제목: S1 title + '2기' (예: `런지 챌린지 2기`)
- `pass_count` = 기본 5 유지
- 시즌 식별: `challenges.season_number` 컬럼 신설
- S1 상태 'active' → S2 시작 시점에 'ended' 전환
- S2 전용 홈 카드/회고 **신규 컴포넌트** (디자인 확정 후 Phase 2 로 분리)

### Step 8 — 운영 SQL 템플릿
`scripts/sql/launch-lunge-s2.sql` (idempotent, 트랜잭션):
```sql
BEGIN;

-- 1) S1 종료
UPDATE challenges
   SET status = 'ended'
 WHERE season_number = 1 AND status = 'active';

-- 2) S2 insert
INSERT INTO challenges (
  title, description, goal_per_day, duration_days,
  start_date, registration_deadline, pass_count, status,
  image_url, goal_min, rest_days_per_week, season_number
)
VALUES (
  '<S2_TITLE>',           -- 예: '런지 챌린지 2기'
  '<S2_DESCRIPTION>',     -- 예: '하루 100개, 30일. 다시 뛰는 가을.'
  100,                    -- goal_per_day
  30,                     -- duration_days
  '<S2_START_DATE>',      -- YYYY-MM-DD
  '<S2_REGISTRATION_DEADLINE>', -- YYYY-MM-DD
  5,                      -- pass_count
  'upcoming',             -- 'upcoming' 유지, start_date 도달 시 'active' 로 수동 전환
  '<S2_IMAGE_URL_OR_NULL>',
  10,                     -- goal_min
  1,                      -- rest_days_per_week
  2                       -- season_number
)
ON CONFLICT DO NOTHING;   -- (title 유니크 아닌 경우 별도 가드 필요시 수정)

COMMIT;
```
